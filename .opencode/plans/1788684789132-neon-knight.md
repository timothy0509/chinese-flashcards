# Flashcard site plan

## Goal
Build a static flashcard site from answers.md. The file holds 691 entries across 12 chapters in the form `題號. 原句｜粗體字：X｜答案：Y`. answers.md is temporary and stays untracked. The site ships with committed JSON derived from it.

User choices guide this plan. Stack is Vite plus React plus TS. UI text is Traditional Chinese. Host is Vercel or Netlify. Features are flip plus shuffle plus filter, with SM-2 spaced repetition stored in localStorage.

## Data pipeline
answers.md will not be committed, so parse it once and commit the result.

1. Add `scripts/parse-answers.mjs`. It reads `answers.md` at repo root, splits on `## ` headers for chapter names, then parses each line as `題號. 原句｜答案：Y` where the tested term is the `**bold**` span inside the sentence. Output sentence strips the markers.
2. Output is `src/data/cards.json`. Each record has `id`, `chapter`, `num`, `sentence`, `term`, `answer`. `id` is `${chapterIndex}-${num}`. Keep original sentence intact.
3. The parser also writes `src/data/chapters.json` with chapter name and card count.
4. Add a validation step. The parser fails on unparsed lines and prints line numbers. Expected count is 691. Run with `node scripts/parse-answers.mjs`.
5. Commit `src/data/cards.json` and `src/data/chapters.json`. Add `answers.md` to `.gitignore`.

Edge cases in the data. Some terms contain multiple words such as `辭謝固請`. Some answers contain notes like `通「X」` or usage tags like `(作動詞用)`. The parser keeps answers as raw strings. The UI highlights the term in the sentence by simple substring match, and falls back to plain sentence plus a separate term field when no match exists.

## App structure
Scaffold with `npm create vite@latest . -- --template react-ts` in the empty repo. Keep the default Vite layout.

New files:
- `src/data/cards.json`, `src/data/chapters.json` from the parser
- `src/lib/srs.ts` for SM-2 logic (easiness, interval, repetitions, due date, grading 0 to 5 or 再來 / 記得)
- `src/lib/storage.ts` for localStorage read and write of progress keyed by card id
- `src/lib/filter.ts` for chapter filter and text search
- `src/components/Flashcard.tsx` for front (sentence with highlighted term) and back (answer), click or Space to flip
- `src/components/Controls.tsx` for shuffle, next, prev, chapter select, search input, mode toggle
- `src/components/StudyModes.tsx` for 全部瀏覽 vs 今日複習 (due cards only)
- `src/App.tsx` wires state, deck order, progress stats
- `src/index.css` for basic styling, large Chinese type, mobile friendly
- `scripts/parse-answers.mjs` as above

No backend. No router needed. State lives in React plus localStorage.

## Study behavior
- Default deck is all cards, shuffled. Filter narrows by chapter or search text across sentence, term, answer.
- Flip shows the answer. Keyboard supports Space to flip, arrows for next and prev.
- Review mode uses SM-2. Each card stores easiness, interval, repetitions, due date, last reviewed. 今日複習 shows only due cards. Grading updates the schedule.
- Progress bar shows 已學, 待複習, 已掌握 counts. A 重置進度 button clears localStorage.
- UI strings are Traditional Chinese. Examples: 翻面, 洗牌, 下一張, 章節篩選, 搜尋, 今日複習.

## Styling
Keep it plain. System fonts for Chinese, large card area, one accent color. Works on phone and desktop. No UI framework. This keeps the Vercel and Netlify build fast.

## Deployment
- Build output is static `dist/`. Both Vercel and Netlify build with `npm run build`.
- Add `vercel.json` or `netlify.toml` only if rewrites are needed. For a single page app with no routing, neither file is required.
- Set Node 20 in host settings.

## Verification
1. Run `node scripts/parse-answers.mjs` and confirm 691 cards and 12 chapters. Spot check 5 entries against answers.md.
2. Run `npm install`, `npm run dev`, open the local URL. Check flip, shuffle, chapter filter, search, and that refresh keeps SRS progress from localStorage.
3. Run `npm run build` and `npm run preview`. Confirm no TS errors and `dist/` serves.
4. Delete or move answers.md temporarily and rebuild. The build must still pass because it reads only committed JSON.
